开始使用

安装一次，添加账户并创建路由，然后在工具中设置 Base URL 与 sk-gt。

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. 安装 CLI

curl -fsSL https://llms.goodtek.xyz/install.sh | bash
llms --help

2. 登录

llms login

3. 账户与路由

llms add
llms route create
llms route key <slug>

4. 接入工具

设置值
Base URLhttps://llms.goodtek.xyz/r/<slug>/v1
API Keysk-gt-…

和 OpenAI 一样，只有 chat/completions 一个入口。需要搜索或图片时，在同一请求的 tools 里加 web_search / generate_image。API 指南 · API 文档

5. 云端（目前免费）

自托管运维嫌重就用托管云 — 目前免费。需要该路径请用 llms signal 告诉我们。也可 llms plan。

llms plan
llms status

6. 自托管

想在自己的电脑或服务器上跑？开源 openllms 自托管时不限用量、免费。一份 Compose 即可开始，详情见 GitHub README。

如果有帮助，请到 GitHub 点个 ★ Star。

git clone https://github.com/goodtek-xyz/openllms
cd openllms
docker compose -f deploy/oss/docker-compose.yml up --build
