安装指南 云端

路由

如何在你的席位间分流

按策略调度你已有的 ChatGPT、Claude 席位。每个路由 URL 选一种策略；首个 token 到达客户端前完成故障转移。

  • failover — 主账号失败再试备用
  • balance — 在健康账号间轮询
  • prefer-primary — 主席约 80/20 优先
  • fill-first — 先用满一个席位，再切下一个
  • quota-first — 优先剩余更多的席位（相同时选更快重置的）
  • reset-soon — 优先 7d 窗口更快重置的席位
  • steward — 剩余×重置紧急度（优先 OAuth）

用 llms route 选择，用 llms status 查看。

API

如何调用

与 OpenAI Chat Completions 相同——只有一个入口。Cursor、代理、脚本通用。

Base URL https://llms.goodtek.xyz/r/<slug>/v1 调用 POST …/chat/completions 认证 Authorization: Bearer sk-gt-…

和 OpenAI 一样：向 POST …/chat/completions 发送 messages 即可。需要搜索或图片时，在同一请求的 tools 里加 web_search / generate_image——没有单独的 API。

API 文档

坦诚

你的账号 · 官方 OAuth · 限额照旧

只用官方 OAuth 连接你拥有的账号。不共享、不转售凭证。不伪装成官方 CLI。供应商限额与条款仍然适用。

自托管

想自己跑就用 openllms

不想用我们的云？也可以在自己的电脑或服务器上跑。开源 openllms 自托管时不限用量、免费。用 Docker 一次拉起即可；域名、安全、运维自己管。账号连接和状态查看用 CLI。

FAQ

常见问题

llms 是什么？

把已在付的 ChatGPT、Claude 订阅变成 API。一个 ChatGPT Pro、一个 Claude，或多个 GPT 账号都能捆成一个地址，剩余额度自动管理。

支持哪些工具？

任何支持 OpenAI 兼容 Base URL 的 IDE、CLI、机器人。

需要自建服务器吗？

不是必须。运维嫌重就用 云端（目前免费）。自建请看 openllms。需要云端路径可用 llms signal 告诉我们。
