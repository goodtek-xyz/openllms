llms

goodtek が作っています

すでに払っているサブスクで
API を作れます。

ChatGPT Pro ひとつ、Claude ひとつ、あるいは GPT アカウントが複数でも—すでに払っているサブスクを llms にまとめれば、Cursor・IDE・ボットにはアドレスひとつだけ。呼び出しは OpenAI 互換の chat/completions、残り枠は自動で振り分けます。

インストール クラウド

ルーティング

あなたの席をどう分けるか

すでに持っている ChatGPT・Claude の席を、ルート URL ごとの方針で振り分けます。最初のトークンがクライアントに届く前にフェイルオーバーします。

  • failover — 主系→予備
  • balance — 健全アカウントをラウンドロビン
  • prefer-primary — 主席を 80/20 で優先
  • fill-first — 1席を使い切ってから次へ
  • quota-first — 残り枠が多い席を優先（同率ならリセットが近い方）
  • reset-soon — 7d 枠のリセットが近い席から
  • steward — 残量×リセット緊急度（OAuth 優先）

llms route で選び、llms status で確認。

API

呼び出し方

OpenAI Chat Completions と同じ。エンドポイントはひとつ。Cursor・エージェント・スクリプト共通です。

Base URL https://llms.goodtek.xyz/r/<slug>/v1 呼び出し POST …/chat/completions 認証 Authorization: Bearer sk-gt-…

OpenAI と同じです。POST …/chat/completions に messages を送るだけ。検索や画像が必要なら、同じリクエストの tools に web_search / generate_image を追加。別 API はありません。

API ドキュメント

正直に

自分のアカウント · 公式 OAuth · 上限はそのまま

公式 OAuth であなたが所有するアカウントだけを繋ぎます。資格情報の共有・転売はしません。公式 CLI への偽装もしません。プロバイダ上限と ToS はそのままです。

セルフホステッド

自分で動かすなら openllms

クラウドではなく、自分の PC やサーバーで動かしたいとき用です。オープンソースの openllms はセルフホストなら使い放題・無料。Docker で一気に起動でき、ドメイン・セキュリティ・運用はご自身で。アカウント接続と状態確認は CLI で行います。

$ docker compose -f deploy/oss/docker-compose.yml up --build

FAQ

よくある質問

llms とは？

すでに払っている ChatGPT・Claude サブスクを API として使う中継です。ChatGPT Pro ひとつ、Claude ひとつ、GPT が複数でも URL ひとつにまとめ、残り枠は自動管理します。

どんなツールに使える？

OpenAI 互換 Base URL を受け付ける IDE・CLI・ボットならどれでも。

自前ホストは必要？

必須ではありません。運用が重いと感じたら クラウド（いま無料）へ。自分で回すなら openllms。クラウドが必要なら CLI で llms signal と教えてください。
