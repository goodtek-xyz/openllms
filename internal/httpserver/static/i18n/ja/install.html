一度インストールし、アカウントとルートを作ってから、ツールに Base URL と sk-gt を設定します。

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. CLI インストール

curl -fsSL https://llms.goodtek.xyz/install.sh | bash
llms --help

2. ログイン

llms login

3. アカウントとルート

llms add
llms route create
llms route key <slug>

5. クラウド（いま無料）

箱の運用が重いと感じたらホスト版クラウドへ — いま無料です。必要なら CLI で llms signal と教えてください。プランは llms plan。

llms plan
llms status

6. セルフホステッド

自分の PC やサーバーで動かしたいときはオープンソースの openllms。セルフホストなら使い放題・無料です。Compose ひとつで始められ、詳細は GitHub README にあります。

役立ったら GitHub で ★ Star をお願いします。

git clone https://github.com/goodtek-xyz/openllms
cd openllms
docker compose -f deploy/oss/docker-compose.yml up --build
