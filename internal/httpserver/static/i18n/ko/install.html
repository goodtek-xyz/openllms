시작하기

터미널에서 계정을 연결하고 API 주소를 만든 다음, 쓰는 도구에 Base URL과 sk-gt 키만 넣으면 끝이에요.

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. CLI 설치

Linux / macOS (amd64, arm64)에서 아래 한 줄이면 됩니다.

curl -fsSL https://llms.goodtek.xyz/install.sh | bash
llms --help

설치 파일은 사이트 /dist에서 받아요. GitHub 로그인은 필요 없습니다. 확인: llms version

2. 로그인

llms login

GitHub로 로그인하면 sk-gt 키가 저장돼요.

3. 계정 · 라우트

llms add
llms route create
llms route key <slug>

Claude·Codex 구독이나 OpenAI·DeepSeek 같은 API 키를 등록할 수 있어요. 라우트를 만들면 /r/<slug>/v1 주소가 생깁니다.

4. 도구에 연결

설정값
Base URLhttps://llms.goodtek.xyz/r/<slug>/v1
API Keysk-gt-… (llms route key)
 
curl -sS https://llms.goodtek.xyz/r/<slug>/v1/chat/completions \
  -H "Authorization: Bearer sk-gt-…" \
  -H "Content-Type: application/json" \
  -d '{"model":"…","messages":[{"role":"user","content":"안녕"}]}'

OpenAI와 같이 chat/completions 한 엔드포인트입니다. 검색·이미지가 필요하면 같은 요청의 tools에 web_search / generate_image를 넣으면 됩니다. API 안내 · API 문서

5. 클라우드 (지금은 무료)

서버 운영이 부담되면 호스팅 클라우드를 쓰면 되고, 지금은 무료예요. 클라우드가 필요하다고 느끼면 터미널에서 llms signal로 알려 주세요. 플랜은 llms plan.

llms plan
llms status

6. 셀프 호스티드

우리 클라우드 대신 내 PC나 서버에서 돌리고 싶다면 오픈소스 openllms를 쓰면 돼요. 셀프호스트면 무제한·무료이고, 아래처럼 Docker Compose로 시작할 수 있어요. 자세한 설명은 GitHub README에 있습니다.

도움이 됐다면 GitHub에서 ★ Star 한 번만 눌러 주세요.

git clone https://github.com/goodtek-xyz/openllms
cd openllms
docker compose -f deploy/oss/docker-compose.yml up --build
