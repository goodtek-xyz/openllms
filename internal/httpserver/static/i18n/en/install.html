Get started

Install once, add accounts, create a route, then set Base URL and sk-gt in your tool.

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. Install CLI

curl -fsSL https://llms.goodtek.xyz/install.sh | bash
llms --help

2. Log in

llms login

3. Accounts & routes

llms add
llms route create
llms route key <slug>

4. Connect your tool

SettingValue
Base URLhttps://llms.goodtek.xyz/r/<slug>/v1
API Keysk-gt-…

Same as OpenAI: one chat/completions endpoint. Need search or images? Put web_search / generate_image in tools on that same request. API guide · API docs

5. Cloud (free for now)

If self-host ops feel heavy, use hosted cloud — free for now. If you need that path, tell us with llms signal. Also: llms plan.

llms plan
llms status

6. Self-Hosted

Want your own box? Open-source openllms is free with no usage cap when you self-host. One Compose file to start; details live in the GitHub README.

If it helps, please ★ Star on GitHub.

git clone https://github.com/goodtek-xyz/openllms
cd openllms
docker compose -f deploy/oss/docker-compose.yml up --build
