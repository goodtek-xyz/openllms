Routing

How we split across your seats

llms orchestrates the ChatGPT and Claude seats you already own. Each route URL picks a policy; failover runs before the first token hits your client.

  • failover — primary, then backup
  • balance — round-robin across healthy accounts
  • prefer-primary — soft 80/20 preference for your main seat
  • fill-first — burn one seat, then the next
  • quota-first — prefer more remaining (earliest reset on ties)
  • reset-soon — burn the seat whose 7d window resets soonest
  • steward — score remaining × reset urgency (prefer OAuth)

Choose with llms route; watch with llms status.

API

How to call

Same as OpenAI Chat Completions — one endpoint. Same shape for Cursor, agents, and scripts.

Base URL https://llms.goodtek.xyz/r/<slug>/v1 Call POST …/chat/completions Auth Authorization: Bearer sk-gt-…

Same as OpenAI: POST …/chat/completions with messages. Need search or images? Add web_search / generate_image in tools on that same request — no separate APIs.

$ curl -sS "https://llms.goodtek.xyz/r/MY_ROUTE/v1/chat/completions" \
-H "Authorization: Bearer sk-gt-…" \
-H "Content-Type: application/json" \
-d \'{"model":"…","messages":[{"role":"user","content":"Hi"}]}\'

See API docs for details.

FAQ

Questions

What is llms?

It turns subscriptions you already pay for into an API. One ChatGPT Pro, one Claude, or several GPT accounts—bundle them into one URL; we manage remaining quota when you call.

Where do I manage accounts?

The CLI. Use llms login, llms add, llms status, and llms plan.

Cloud vs self-host?

If running a box feels heavy, use cloud — free for now. Prefer your own server? openllms. If cloud matters to how you work, tell us with llms signal.

Do I need to self-host?

No. Use llms.goodtek.xyz. Prefer your own box? Use openllms.
